# File Analyzer

Тестовое задание на позицию Python Backend Developer.

Сервис автоматически скачивает текстовые файлы через внешнее API, сохраняет информацию о них в базе данных и позволяет анализировать содержимое выбранных файлов через веб-интерфейс.

---

## Возможности

### Скачивание файлов

- автоматическое скачивание всех файлов через API;
- получение списка файлов до полного завершения скачивания;
- скачивание не более 3 файлов за один запрос согласно ограничениям API;
- автоматическая отметка файлов как скачанных;
- отображение прогресса скачивания в реальном времени;
- отображение времени начала скачивания (часовой пояс Новосибирска);
- корректная обработка ограничений API (`429 Too Many Requests`, `403 Forbidden`);
- поддержка заголовка `Retry-After` с автоматическим ожиданием перед повторной попыткой.

### Работа со скачанными файлами

- список всех скачанных файлов;
- отображение времени скачивания;
- сортировка по времени скачивания;
- пагинация;
- выбор отдельных файлов;
- выбор всех файлов на текущей странице;
- выбор всех скачанных файлов.

### Анализ файлов

После выбора файлов сервис рассчитывает:

- общую статистику встречаемости цифр 0–9 во всех выбранных файлах;
- статистику по каждому выбранному файлу.

## Установка

Создать виртуальное окружение

```bash
python -m venv .venv
```

Активировать

Windows

```bash
.venv\Scripts\activate
```

Linux/macOS

```bash
source .venv/bin/activate
```

Установить зависимости

```bash
pip install -r requirements.txt
```

## Настройка

Скопировать `.env.example` в `.env`:

```bash
cp .env.example .env   # Linux/macOS
copy .env.example .env # Windows
```

Или создать файл `.env` вручную:


## Особенности реализации

### Работа с ограничениями API

Внешний API ограничивает частоту запросов.

Для предотвращения блокировки сервис:

- выполняет скачивание небольшими партиями;
- делает небольшие задержки между запросами;
- автоматически обрабатывает ответы `429 Too Many Requests`;
- автоматически обрабатывает временную блокировку (`403 Forbidden`);
- использует значение заголовка `Retry-After` для ожидания перед повторным запросом.

Такой подход обеспечивает стабильное скачивание большого количества файлов без вмешательства пользователя.

### Безопасность

При распаковке ZIP-архивов выполняется проверка пути назначения для защиты от Path Traversal (Zip Slip).
